# v1.3.0

Windows capture reliability improvements, with two experimental Windows 11 capture shortcuts.

- Alt+P now captures GPU desktops through DXGI, with GDI as a compatibility fallback.
- Alt+O tests Windows Graphics Capture on the active monitor(s), without falling back to another method.
- Alt+Shift+O tests direct foreground-window capture through WGC. The target is selected when the shortcut is pressed.
- Experimental WGC captures keep Windows' capture border enabled. Both shortcuts work while Cronq is hidden and respect the Alt+K lock.
- WGC selects the GPU associated with the target display where possible and recreates its device/session once after device loss.
- Entirely black captures, protected foreground windows and inaccessible desktops report an error instead of publishing a black screenshot.
- Capture and encoding run in the background. Busy clipboard publication is retried; disk and clipboard failures are reported separately.
- PNGs and latest-image indexes are published through temporary files. Experimental images have separate folders and latest-image indexes.
- Diagnostics distinguish unknown display affinity, explicit protection, capture access denial, GPU device loss and unsupported APIs, without logging window titles or app content.

Experimental images: `%LOCALAPPDATA%\cronq\snaps-wgc` and `snaps-wgc-window`.

The WGC paths are experimental. Native interactive Windows 11 GPU, HDR, hybrid-GPU and focus-app validation remains pending; this release does not promise to recover OS-protected pixels. See `windows/SCREENSHOTS.md` for the test commands and known limits.

The website's existing secret-code download resolves the latest `cronq-setup.exe` release asset, including this version.
