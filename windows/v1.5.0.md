# v1.5.0

Updates the Windows and Linux overlays to a compact, ChatGPT-only utility with a matching error-page interface.

- Replaces the home screen with an error-page layout. Double-click **recovery** to open ChatGPT.
- Keeps keyboard and ghost indicators in the header. Four faint footer dots retain the previous action order, with no hover effects or divider.
- Removes on-screen status notification popups.
- Preserves overlay typing when hidden with Alt+X until focus is deliberately released or moved elsewhere.
- Sets ghost opacity to 50% and restores 100% on returning to normal mode.
- Fixes Escape cancellation of the kill confirmation.
- Removes the standalone browser and Ghost Typer; retains existing ChatGPT, navigation, screenshot, and keyboard shortcuts.
- Adds Linux release packaging and updating, with platform acceptance tests and Windows UI regression coverage.

## Downloads

- **Windows:** `cronq-setup.exe`
- **Linux x86_64 (X11):** `cronq-linux-x86_64.tar.gz`
- SHA-256 checksum files are provided for both downloads.

The protected-content black-screenshot issue remains unresolved. The repository includes a separate experimental renderer capture probe; it is not integrated into the app or claimed as a working fix. Licensing documentation and an initial superadmin configuration scaffold are also included in source only.
