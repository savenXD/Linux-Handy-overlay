## What this proves

Windows successfully reported exclude-from-capture on the visible CodeTantra main window. Combined with the recovered application call, this establishes that the identified mechanism was active during the recorded user session. The user confirms they reached an ADS coding question and attempted screenshots during the recording.

`0x11` is `WDA_EXCLUDEFROMCAPTURE`; `0x1` is monitor-only; `0x0` is no display-affinity restriction on the queried window. Other mechanisms can coexist. [Microsoft documentation](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity).

## What this does not prove

The main PID stays unchanged while observed. The first visible main-window sample already has capture protection. Therefore the log does not establish a Resume-triggered restart or a transition from unprotected login to protected course. The user-reported short restart and statically recovered relaunch path remain consistent, but are not time-aligned here.

The probe did not collect window contents, titles, screenshots, course URLs, configuration values, IPC messages, screenshot API traces, or exact user-action timestamps. It cannot tell which capture method produced which output. A one-second poll also cannot exclude brief transitions between samples.

There is **no demonstrated bypass** in the log. The unprotected hidden/auxiliary windows do not mean the coding content can be captured through them.

## Probe behavior and privacy

The preserved PowerShell/CMD files enumerate only matching `CodeTantra-SEA` process windows and read visibility, minimized, topmost, foreground, and display-affinity state. They do not modify the application, inject code, clear affinity, capture page contents, or request elevation. The launcher applies a process-local execution-policy override; it does not persistently change machine policy.

Initially the probe could only be reviewed on Linux. The returned log now provides evidence that it ran and successfully read affinity on the user's Windows machine. This does not test its behavior on every Windows configuration.
