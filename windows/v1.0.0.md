# v1.0.0

Cronq 1.0.0 for Windows 10/11 x64.

## Download

Download **cronq-setup.exe** and run it. Setup installs per-user; build tools and administrator rights
are not needed for the normal installation. The Microsoft Edge WebView2 runtime is required; setup
attempts to install it if missing. This installer is unsigned and Windows may show a reputation warning.
`SHA256SUMS.txt` accompanies the installer for download verification.

## Included in this Windows release

- Light and Dark appearances throughout Cronq and Ghost Typer.
- Transparent, minimal camouflage: no outer border, header, footer, or window controls; Home keeps
  clickable app icons and the ChatGPT view prioritizes conversation text and the message field.
- Fresh-install default: black text with no background. **Alt+T** switches to white text without
  disabling camouflage. **Alt+C** toggles camouflage and normal controls.
- **Alt+Left / Alt+Right** instantly dock to the bottom-left/right of the configured display and save
  the corner for future launches, respecting the taskbar work area and configured margin.
- Fixed temporary lock: **Alt+K** hides Cronq and disables its normal shortcuts; **Alt+K+X** unlocks it.
  Alt+X no longer bypasses the lock, and locking cancels Ghost Typer.
- **Alt+Shift+K** retains its separate removal confirmation: Enter removes Cronq and its app data;
  Esc or timeout cancels. Use `cronq kill` to stop without deleting files.
- A minimal static download frontend in `frontend/`, linked to the latest published installer.

## Verification and limits

Native Windows tests cover actual desktop transparency with both text colors, configuration persistence,
temporary locking, camouflage shortcuts, and saved corner movement. Browser styling tests use an isolated
local ChatGPT-style fixture; changes to ChatGPT's live markup may require updates.

Transparency uses a Windows color key: white image pixels disappear in black-text camouflage, and
black image pixels disappear in white-text camouflage. Empty transparent areas pass mouse clicks through;
click visible text/placeholder to interact, or press Alt+C to restore the normal UI. Other websites may
keep their own fixed styling. Existing user settings are preserved; fresh installations use transparent
black text by default. See `windows/README.md` and `windows/PARITY.md` for other platform limits.
