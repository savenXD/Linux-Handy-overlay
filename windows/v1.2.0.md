# v1.2.0

Reliability, privacy and performance release for Windows 10/11 x64.

## Fixes

- Shortcuts no longer misfire after Ctrl+Alt+Del, the lock screen, UAC or an admin window: a missed Alt
  release could turn plain letters (X, K, C, arrows ...) into Cronq shortcuts, and a missed Win release
  could disable all shortcuts.
- Camouflage: clicking a see-through area now types into the app underneath. Before, Cronq also took
  the keyboard and Ctrl+C/V for up to 60 seconds.
- While the overlay is hidden, only Alt+X, Alt+P, Alt+W, Alt+K and Alt+Shift+K belong to Cronq. Alt+Left
  (Back), Alt+D, Alt+F and the other layout keys work normally in your apps again.
- Kill switch: any key other than Enter cancels it, and while hidden it expires after 5 s, so normal
  typing can never confirm it.
- Ghost Writer stops reliably when you switch windows, even briefly.
- A window left on an unplugged monitor comes back on screen; maximize-height and Snap use the screen
  you are working on.
- Pasting an unreadable clipboard image no longer pastes an old screenshot instead.

## Hidden from recordings

- The embedded browser's own popups cannot be excluded from capture (they belong to a Microsoft
  process), so they are now turned off: right-click menus, DevTools, browser shortcut keys, autofill and
  password bubbles, permission prompts, alert dialogs, the download bubble and all tooltips.
- Still visible to recorders: website dropdown lists and the file picker ("Attach file"). Paste or Snap instead.
- The 150 ms background process sweep is gone (it could not protect other processes' windows anyway).

## Reliability

- Crash restarts back off (2 s, 4 s ... 60 s) instead of looping, stop when a restart cannot help, and
  come back hidden. The Start Menu shortcut and setup now launch with crash recovery.
- WebView2 crash loops back off; a browser that fails to start is retried automatically.
- Crashes write a small minidump next to the crash report (newest 3 kept).
- Kill switch cleanup is native (no PowerShell), so it also works where scripts are blocked.
- The command pipe is per user session and only accessible to your account.

## Lighter

- No system-wide mouse hook while hidden; hidden web views are throttled (ChatGPT can finish an answer,
  the browser page is suspended); the browser page is created only when first opened.
- Snap encodes and saves on a background thread: no freeze on large multi-monitor captures.
- Gentler stay-on-top guard that stops fighting windows it cannot beat.

## Privacy

- Snaps are saved to `%LOCALAPPDATA%\cronq\snaps` (not `Pictures`, which OneDrive often syncs).
- Logs record hosts, not full URLs, never other apps' window titles or typed text; they rotate while running.

## New

- `cronq update`: checks GitHub when you run it (never on its own), verifies the installer against the
  release's `SHA256SUMS.txt`, then starts setup.

## Limits

Releases are not code-signed, so Windows SmartScreen may warn on first download. Native Windows
verification of capture exclusion (Zoom/Meet/OBS) is still pending, see PARITY.md.
