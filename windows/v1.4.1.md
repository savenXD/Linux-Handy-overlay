# v1.4.1

Adds experimental god-copy for Windows 11:

- Ctrl+Left Alt+C reads selected text through standard EDIT messages or UI Automation, retains it in memory, and attempts clipboard publication.
- Ctrl+Left Alt+V sends retained Unicode text independently of clipboard paste.
- Selection reading runs in a bounded helper process; clipboard contention preserves the internal copy.
- Password fields are excluded; failed reads preserve the previous copy with an explicit notice. Focus changes stop paste, and locking/reset/shutdown erase retained text.
- AltGr remains available for normal typing.

Validation: Linux cross-build, 22 CTest cases, and 16 Wine interactive checks passed. Native Windows/MSVC build checks are recorded by this release's GitHub Actions run. The interaction fixture verifies standard EDIT selection reading, not Chromium UI Automation or CodeTantra.

**Experimental:** CodeTantra compatibility and universal copying/pasting remain unverified. This release does not fix the unresolved protected black-screenshot issue. See windows/GOD_COPY.md and WINDOWS_AGENT_HANDOFF.md for the testing limits and Windows continuation checklist.

Includes the Windows SDK COM header prerequisites for native MSVC compilation. The v1.4.0 build failed before publication; v1.4.1 is the intended downloadable release.
