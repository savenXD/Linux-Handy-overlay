# v1.1.1

Privacy release for Windows 10/11 x64.

## Hidden from screen recorders (new, on by default)

- Cronq excludes itself from screen capture with `WDA_EXCLUDEFROMCAPTURE`. You still see it; full-screen
  recordings, screen sharing (Zoom, Meet, Teams, browser `getDisplayMedia`, OBS display capture) and
  screenshots do not contain it.
- Popups, menus and prompts from the embedded browser (WebView2) and the kill-confirmation window are
  also excluded, via a light background sweep of Cronq's own processes (every 150 ms).
- Fails closed: if Windows cannot apply the flag (older than 10 version 2004), Cronq shows a message and
  does not start, instead of running visible.
- Alt+P snap restores the protected state after a capture instead of dropping it.
- Opt out with `hide_from_capture = false` under `[Privacy]` in `config.ini`; changes apply on reload.

## Limits

Only Cronq is hidden: other windows on your screen are still captured. A camera pointed at the screen,
a capture card, or recording below Windows (hypervisor, kernel-level) are not covered. A popup can be
visible for up to one sweep interval before it is marked. Cross-compile and unit tests pass; native
Windows capture verification (Zoom/Meet/OBS) is still pending, see PARITY.md.
